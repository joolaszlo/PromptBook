# Changes

PromptBook is a modified fork of TagStudio.

Original project:
- TagStudio
- Original repository: https://github.com/TagStudioDev/TagStudio
- Original authors and contributors: TagStudio Contributors

PromptBook changes the focus of the original application from general file organization to prompt-based workflows and AI-generated media organization.

Relevant date:
- 2026

- PromptBook

## Summary of Main Changes

### Branding and Identity

The visible application identity has been changed from TagStudio to PromptBook.

This includes changes such as:

- application name
- visible UI text
- project description
- documentation wording
- PromptBook-specific branding
- PromptBook-specific README content
- PromptBook-specific project direction

Some internal names, module names, paths, settings, or inherited identifiers may still reference TagStudio while the conversion is in progress.

### Project Focus

The original TagStudio project is focused on general file and media organization.

PromptBook changes the intended workflow toward organizing:

- prompts
- generated images
- generated videos
- text outputs
- creative notes
- related source files
- prompt and output relationships
- AI-generated media workflows

The goal is to make prompts and their generated results easier to search, review, compare, reuse, and archive.

### Documentation

The documentation has been rewritten or adjusted for PromptBook.

Main documentation changes include:

- README rewritten for PromptBook
- project description changed
- usage examples adjusted toward prompt workflows
- origin and license information added
- TagStudio attribution added
- source code availability information added
- project status information added
- PromptBook-specific FAQ added

### User Interface Text

User-facing text has been changed to better match PromptBook.

This may include:

- application labels
- menu text
- dialog text
- tooltip text
- settings text
- help text
- about dialog text
- translation strings

The goal is to reduce TagStudio-specific wording and replace it with PromptBook-specific terminology.

### Search and Filtering

Search-related behavior and interface text have been adjusted for PromptBook workflows.

Main changes may include:

- search behavior adjusted for selected tags and user text
- search options adjusted for tags, titles, and prompt-related text
- search UI layout changes
- reset and clear search behavior changes
- improved separation between selected tags and typed search text

### Tags and Categories

Tag-related behavior and presentation have been adjusted for the PromptBook workflow.

Main changes may include:

- selected tag display changes
- pinned or favorite tag behavior changes
- visual highlighting changes
- terminology adjusted for prompt organization
- category-related UI adjustments

Sidebar and metadata-related UI behavior has been adjusted.

### Thumbnail and Entry Display

Thumbnail and entry presentation has been adjusted.
