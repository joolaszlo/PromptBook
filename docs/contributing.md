# Contributing to PromptBook

PromptBook is currently an early personal fork of TagStudio.

The project is still being renamed, cleaned up, and adjusted for prompt-based workflows and AI-generated media organization. Because of this, external contributions are currently limited.

## What Is Welcome?

For now, the most useful contributions are:

- bug reports
- typo fixes
- suggestions related to prompt and generated media workflows

Large pull requests, major refactors, new features, or UI redesigns should be discussed first.
