# Changelog

All notable changes to PromptBook will be documented in this file.

PromptBook is a modified fork of TagStudio. For the original project's history, see the TagStudio repository:

https://github.com/TagStudioDev/TagStudio

## [1.0.0] - 2026-05-22

### Added

- Initial PromptBook release.
- PromptBook branding and project identity.
- Prompt-focused README and documentation.
- PromptBook-specific origin, license, and source availability information.
- `CHANGES.md` file describing the main differences from TagStudio.

### Changed

- Changed the application focus from general file organization to prompt and generated media organization.
- Updated user-facing text from TagStudio-focused wording to PromptBook-focused wording.
- Adjusted search and filtering behavior for PromptBook workflows.
- Adjusted thumbnail and entry display behavior.
- Adjusted sidebar and metadata display behavior.
- Updated About/license/origin information.
- Updated release/update handling for the PromptBook repository.

### Removed

- Removed or replaced outdated TagStudio-specific README content.
- Removed or replaced TagStudio-specific documentation sections that do not apply to PromptBook.

### Notes

- PromptBook is still based on the TagStudio codebase.
- Some internal names, paths, settings, or inherited references may still mention TagStudio.
- This is an early fork, so behavior inherited from TagStudio may still be present.
